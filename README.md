## 🔧 Troubleshooting
Check these common solutions if the program does not start as expected.

**The terminal says command not found.**
If the computer does not recognize the command, you need to restart your terminal. Close the black window and reopen it. This forces the computer to refresh the list of available programs.

**The program closes immediately.**
This often happens if your API key is invalid. Open the configuration file in your user folder and verify the key matches the one provided by your dashboard.

**I see a permission error.**
Run the command prompt as an administrator. Right-click the command prompt icon in your start menu and select "Run as administrator."

## 🔒 Security
The software keeps your data local. It sends your inputs to the API endpoints and returns the results to your screen. It does not store your private keys in plain text on your hard drive. Always keep your API key secret and do not share it with others.
